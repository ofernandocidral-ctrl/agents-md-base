# AGENTS.md base

Um modelo de `AGENTS.md` e um prompt que o adapta ao seu projeto, para todas as IAs que você usa seguirem as mesmas regras. A regra central: nenhuma IA assume que sabe o que a outra fez, porque memória, histórico, permissões e conexões não são compartilhados entre ferramentas.

## Arquivos

- [AGENTS.md](AGENTS.md): o modelo do protocolo.
- [PROMPT-AGENTS-MD.md](PROMPT-AGENTS-MD.md): o prompt que adapta o modelo ao seu projeto.

## Avisos

Cada ferramenta lê as instruções do seu jeito: confira como a sua versão carrega o AGENTS.md. Não coloque senhas nem chaves de acesso no arquivo.
